# Sreja MT

Statički sajt. Otpremite ceo sadržaj ovog foldera u koren GitHub repozitorijuma, pa uključite
Settings → Pages → Deploy from a branch → `main` / `(root)`.

- `index.html` — početna
- `galerija.html` — galerija
- `assets/`, `ds/`, `support.js`, `image-slot.js` — potrebni za rad (ne brisati)
